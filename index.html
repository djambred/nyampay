Arsitektur Utama: ESP32 sebagai otak utama menerima notifikasi dari server NyamPay via WiFi/MQTT, kemudian memutar file audio (.mp3/.wav) yang tersimpan di SD Card melalui amplifier I2S MAX98357A ke speaker.
⚠ Pull-up Resistor: Semua tombol menggunakan pull-up 10kΩ ke 3.3V. Pin GPIO ESP32 dikonfigurasi sebagai INPUT (bukan INPUT_PULLUP internal) agar lebih stabil di lingkungan dengan noise listrik tinggi.

💡 Tips Efisiensi V2.0: Gunakan modul ESP32-S3 mini untuk ukuran lebih kecil. Ganti MAX98357A dengan PAM8302 jika I2S terlalu kompleks. Order PCB custom via JLCPCB bisa tekan biaya PCB + soldering 50%. Beli komponen pasif (resistor, kapasitor) dalam pack 100pcs untuk harga lebih murah.
Alur Kerja Firmware (Logic Flow)
[ BOOT ] │ ▼ Inisialisasi GPIO, I2S, SPI, SD Card │ ▼ [ KONEKSI WiFi ] ──── Gagal? ──► LED Merah ON ──► Retry setiap 30 detik │ Berhasil ▼ [ KONEKSI MQTT BROKER ] │ Subscribe ke topic: nyampay/{merchant_id}/payment ▼ LED Hijau ON — Status: Siap │ ▼ (loop utama) [ TUNGGU PESAN MQTT ] │ │ Ada pesan masuk? ▼ Parse JSON payload: { "amount": 10000, "currency": "IDR", "merchant": "xxx" } │ ▼ Convert amount → nama file audio 10000 → "10ribu.mp3" 25500 → "25ribu_500.mp3" (atau TTS) │ ▼ Putar audio dari SD Card via I2S → MAX98357 → Speaker │ ▼ [ Kembali ke loop tunggu ] ── Thread paralel: Monitor tombol Vol+/Vol- ── ── Thread paralel: Monitor status WiFi & MQTT reconnect ── ── Thread paralel: Monitor baterai (ADC pin) ──

📶 Provisioning WiFi Merchant Baru: Gunakan WiFiManager — saat pertama kali aktif, ESP32 membuka Access Point "NyamPay-Setup". Merchant buka HP, connect ke AP tersebut, masukkan nama WiFi & password toko. Konfigurasi tersimpan di flash ESP32.
⚠ Keamanan MQTT: Gunakan TLS/SSL untuk koneksi MQTT (port 8883). Setiap device memiliki client_id unik dan token autentikasi. Payload transaksi divalidasi dengan HMAC signature dari server agar tidak bisa dipalsukan.
✅ OTA Update: Firmware dapat diperbarui secara over-the-air dari server NyamPay tanpa perlu kabel. Ini penting untuk perbaikan bug dan penambahan fitur tanpa harus kunjungi tiap merchant.
